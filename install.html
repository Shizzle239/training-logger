Training Logger

Offline-Trainingstagebuch · kein Konto · Daten bleiben auf deinem Gerät.

▶ App jetzt öffnen
📱 Android

In Chrome installieren

  1. Diese Seite in Chrome öffnen, oben „App öffnen" tippen.
  2. Menü (⋮) → „App installieren" bzw. „Zum Startbildschirm".
  3. Vom Startbildschirm öffnen — Vollbild & offline.

Alternativ als APK (falls vom Absender erhalten): Datei öffnen → „Installation aus unbekannten Quellen" einmalig erlauben → installieren.

🍎 iPhone / iPad

In Safari installieren

  1. Diese Seite in Safari öffnen (wichtig: Safari, nicht Chrome).
  2. Teilen-Symbol (Quadrat mit Pfeil ↑) tippen.
  3. „Zum Home-Bildschirm" → Hinzufügen.
  4. App vom Home-Bildschirm öffnen — Vollbild, mit Icon, offline.

Kein App Store / keine APK nötig. Erster Start einmal mit Internet.

▶️ Erste Schritte

Programm laden & loggen

  1. App einmal mit Internet öffnen.
  2. Tab Data → „Programm importieren (JSON)" → erhaltene program.json wählen.
  3. Tab Home → Woche + Tag wählen → Sätze loggen.
💾 Daten sichern

Regelmässig exportieren

  1. Tab Data → „Export JSON (full backup)" → Datei sicher ablegen.
  2. Wiederherstellen: Data → Import JSON.

iPhone löscht App-Daten, wenn die App ~2 Wochen nicht geöffnet wird (Apple-Regel) — dort besonders auf Exporte achten. „Browserdaten löschen" entfernt ebenfalls deine Trainings: vorher exportieren.

Kein Server, keine Synchronisation. Jeder Nutzer hat seine eigene, getrennte Datenhaltung — deine Daten verlassen das Gerät nur, wenn du selbst eine Export-Datei weitergibst.
